# Overview
This project is a car detection application that utilizes OpenCV, a powerful computer vision library, to detect cars in images and videos. The application can process a static image or a video feed, drawing rectangles around detected cars.

Features
Detects cars in a static image.
Detects cars in video streams.
Utilizes a pre-trained Haar Cascade classifier for car detection.
Requirements
Python 3.x
OpenCV library
NumPy library (optional for additional functionalities)
